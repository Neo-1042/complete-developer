# IBM Informix

IBM Informix is an **enterprise class database** optimized
for OLTP (Online Transaction Processing), IoT 
(Internet of Things), or data warehouses. It can be deployed
on a myriad of devices; from super powerful Linux servers to
the Raspberry Pie.

Informix, an object-oriented engine, supports traditional data
types, as well as **extended data types**, including
user-defined types. All types can be used together in
SQL or NoSQL operations.

Informix is available from a free tier to for-purchase options.

**DSA = Dynamic Scalable Architecture**

Informix offers scalability in every device that it runs.
Informix supports JSON/BSON, time-oriented, hierarchical
and user-defined data types.

<u>Example</u>: probes and sensors placed in grain silos
to monitor humidity and temperature.
All of these sensors are connected to small gateway devices
running Informix. 
This sensor data is formatted in a time-oriented
data type for fast insertion, analysis and posible response
actions.

> **TimeSeries Framework** --> To efficiently process
time-oriented data. In a single row, all readings from one
device or sensor will be stored in a "Readings" field.

> **SpatioTemporal** Data --> Data Analysis Tracking Technology.

"What was the state of a truck at time x?"

In-memory Data Warehouse Technology:

> **IWA = Informix Warehouse Accelerator** --> Faster data
warehouse operations. System-speed (memory) rather than
disk-speed.

Informix can be installed on a cluster, thereby
supporting **Distributed Application Processing**.
Plus, the cluster can be configured for **High-Availability**
and **Recovery**.

> Informix allows you to manage thousands of data servers
with a handful of admins.
